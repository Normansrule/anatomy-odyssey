How the numbers are checked

Each calculator evaluates the same expression that produces the worked example, and scripts/check_equations.mjs recomputes every example, renders every formula with KaTeX and compares key results with published values — at least one per chapter, for example the GPS clock offsets in Ashby 2003, Hubble's 0.05″ resolution, Mercury's 43″ per century, the 4.3-day solar-wind trip to Earth and the Planck 2018 age of the Universe. Run it with node scripts/check_equations.mjs --table. Found a mistake? Please open an issue.
