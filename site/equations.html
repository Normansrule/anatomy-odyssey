How the numbers are checked

Each calculator evaluates the same expression that produces the worked example, and scripts/check_equations.mjs recomputes every example, renders every formula with KaTeX and compares key results with published values (for example the GPS clock offsets in Ashby 2003 and the IAU nominal solar luminosity). Run it with node scripts/check_equations.mjs --table. Found a mistake? Please open an issue.
