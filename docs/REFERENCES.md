# References: the Mission Library

This file mirrors [`site/data/library.json`](../site/data/library.json), the data behind the [Library page](../site/library.html). It lists **79 primary documents, datasets, tools, courses and books** chosen for people learning space engineering, grouped by kind.

- **Level**: beginner (no maths needed), intermediate (calculus and physics), expert (primary sources and professional tools).
- Every link was checked against web search results on 26 September 2026. Where an exact document URL could not be confirmed, the verified parent page is linked instead.
- Organisation names appear as plain text. Cosmic Library is not affiliated with any of these organisations.

## Start here: a guided reading path

**Beginner — Launch pad.** No maths required. Build intuition, then build something.

1. [Beginner's Guide to Rockets](https://www.grc.nasa.gov/www/k-12/rocket/): Learn thrust, drag and stability one idea per page.
2. [Basics of Space Flight](https://science.nasa.gov/learn/basics-of-space-flight/): From gravity to interplanetary trajectories in plain words.
3. [Apollo 11 Press Kit](https://www.nasa.gov/wp-content/uploads/static/apollo50th/pdf/A11_PressKit.pdf): See a whole Moon mission laid out as reporters saw it.
4. [NASA's Eyes on the Solar System](https://eyes.nasa.gov/apps/solar-system/): Fly along with real spacecraft in 3D.
5. [NAR Model Rocket Safety Code](https://www.nar.org/ModelRocketSafetyCode): Read the rules, then launch your first model rocket.

**Intermediate — Orbit insertion.** Calculus and physics. Start doing the engineering.

1. [Orbital Mechanics for Engineering Students, 4th ed. (Curtis)](https://shop.elsevier.com/books/orbital-mechanics-for-engineering-students/curtis/978-0-08-102133-0): Work the two-body problem and orbital maneuvers yourself.
2. [16.50 Introduction to Propulsion Systems (MIT OpenCourseWare)](https://ocw.mit.edu/courses/16-50-introduction-to-propulsion-systems-spring-2012/): Derive nozzle flow and the rocket equation properly.
3. [Falcon Payload User's Guide](https://www.spacex.com/assets/media/falcon-users-guide-2025-05-09.pdf): Read what a launch provider promises a payload.
4. [Apollo Flight Journal](https://history.nasa.gov/afj/index.html): Follow every burn of a real lunar mission.
5. [NASA Systems Engineering Handbook (SP-2016-6105 Rev 2)](https://www.nasa.gov/reference/systems-engineering-handbook): Learn how all the pieces become one system.

**Expert — Deep space.** Primary sources and professional tools.

1. [Rocket Propulsion Elements, 9th ed. (Sutton & Biblarz)](https://www.wiley.com/en-us/Rocket+Propulsion+Elements,+9th+Edition-p-9781118753651): The reference for engine design and feed systems.
2. [Saturn V Launch Vehicle Flight Evaluation Report AS-506 (Apollo 11)](https://archive.org/details/nasa_techdoc_19900066485): See how flight data is compared against prediction.
3. [DSN Telecommunications Link Design Handbook (810-005)](https://deepspace.jpl.nasa.gov/dsndocs/810-005/): Close a real deep-space link budget.
4. [NAIF SPICE Toolkit](https://naif.jpl.nasa.gov/naif/toolkit.html): Answer mission geometry questions like a navigator.
5. [Columbia Accident Investigation Board (CAIB) Report, Volume 1](https://sma.nasa.gov/SignificantIncidents/assets/columbia-accident-investigation-board-report-volume-1.pdf): Study how technical and organisational failures combine.
